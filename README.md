# TypeFlow Typing Website

A modern Monkeytype-inspired typing speed test built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure
- `style.css` — modern responsive UI
- `script.js` — typing engine, timer, WPM, accuracy, difficulty and theme

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

No npm, Vite, backend, or external library is required.
